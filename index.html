About

The short version of what I do and where I've done it.

I'm a results-driven IT infrastructure and operations professional with over four years of experience across enterprise system administration, cloud solutions, and security frameworks. I've spent that time at leading telecom and technology firms, managing large-scale infrastructure and department-level budgets.

Day to day, that means planning flow diagrams, HLDs, LLDs and methods of procedure for infrastructure projects; running IS clearance and vulnerability mitigation across Windows and Linux estates; and managing identity and privileged access through Active Directory, SailPoint IAM, and CyberArk PAM.

I also build the tools my own IT division runs on — capex/opex tracking, project visibility, IP inventory, and incident dashboards — using the Microsoft Power Platform, so that infrastructure decisions are made on real data rather than guesswork.
